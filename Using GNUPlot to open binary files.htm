Using GNUPlot to plot bin files from C SDK examples

·        Install GNUPlot

·        Open GNUPlot

·        Change the directory with binary file(s).

cd ‘C:\TEST\picosdk-c-examples\ps6000a\ps6000aTemplate’

·        To plot copy and paste the following lines, changing file name you want to plot-

---------------------------------------------------------------------------

N = 131072

C = 2

plot for [i=0:C] "rapidBlock_Segment1.bin" binary format="%int16" \

     every ::(i*N)::( (i+1)*N - 1 ) \

     u ($0 - i*N):1 \

     title sprintf("Channel %d", i+1)

---------------------------------------------------------------------------

Where N is the number of samples and

where C is the number channels in the file. (Note when using Max. and Min. channel value count as 2 channels not one)

 

Note the bin only contain ADC values not scaled values in voltage. But there is text file created with acquisitions meta data created that contains sample interval and channel settings information.

Currently this file is only created when writing a binary fie in streaming mode and file name starts with “PicoMetaData_Streaming*”
