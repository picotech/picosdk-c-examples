Using GNUPlot to plot bin files from C SDK examples

  • Install GNUPlot: Download it from www.gnuplot.info
  • Open GNUPlot: Launch the application on your machine.
  • Change Directory: Navigate to the folder containing your binary file(s).
    Example: cd 'C:\TEST\picosdk-c-examples\ps6000a\ps6000aTemplate'
  • Plot Your Data: Copy and paste the following lines into the GNUPlot terminal:
N = 131072 C = 2 plot for [i=0:C] "rapidBlock_Segment1.bin" binary format="%int16" \ every ::(i*N)::( (i+1)*N - 1 ) \ u ($0 - i*N):1 \ title sprintf("Channel %d", i+1)
Parameter Guide:
  • N: The number of samples.
  • C: The number of channels.

Note: The bin only contains raw ADC values. Acquisition metadata is currently only created in streaming mode for filenames starting with "PicoMetaData_Streaming*".
